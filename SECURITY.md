# Security Policy

## Reporting a vulnerability

Report a vulnerability as an [issue in this repository](https://github.com/bechtleav360/AVS.AI.Blueprint.AgenticService/issues/new) and start the title with `Security:`.

Issues are public. Describe the affected component, the version and the impact, but leave out anything that would help others exploit the vulnerability before it is fixed:

- no working exploit or step-by-step attack
- no credentials, tokens, keys or other secrets, not even expired ones
- no data from your own systems or logs

If the maintainers need details that should not be public, they ask for them in the issue and agree on a private channel with you.

## Fixed versions

A fix is released as a new version of `avs-blueprint-agents` on PyPI and noted in the [changelog](CHANGELOG.md). Older versions do not get backports, so upgrade to the latest release.
